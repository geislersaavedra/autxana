# Autxana

**Tech Stack:** React (Next.js), Tailwind CSS, Framer Motion, Lucide Icons e integraciones con LLM (Gemini) para consultoría inteligente.

**Scope:** Autxana es una plataforma de servicios profesionales especializada en Ingeniería 4.0, Telecomunicaciones, IT y Gestión de Proyectos (PMO). Ofrece herramientas de auditoría técnica, oficina técnica (BIM/Estructuras/Telecom), consultoría en transformación digital, ciberseguridad y formación especializada a través de AX Academy. Incluye un asistente virtual de IA para soporte en normativas y procesos técnicos, centralizando la inteligencia operativa para infraestructuras y proyectos industriales complejos.
